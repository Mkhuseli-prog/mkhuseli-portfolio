# 💼 Mkhuseli Nyamfu | Portfolio Website

Welcome to my personal portfolio website, built to showcase my skills, projects, and aspirations as an aspiring web developer. This responsive site was created using **HTML**, **CSS**, and **JavaScript**, with enhancements like **scroll animations**, **dark mode**, and **interactive modals**.

---

## 🚀 Live Preview

🔗 [View Portfolio on GitHub Pages](https://github.com/Mkhuseli-prog/mkhuseli-portfolio/)

---

## 📌 Features

- Clean and responsive design
- Smooth scroll navigation
- Dark/light theme toggle
- Modal popups for project details
- Skill bars with animated progress indicators
- Scroll-to-top button
- Contact form integrated with Formspree
- Chatbot integration (Dialogflow)

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (with responsive layout and theming)
- JavaScript (ES6)
- [AOS - Animate On Scroll](https://michalsnik.github.io/aos/)
- [Formspree](https://formspree.io) for form handling
- GitHub Pages for deployment
